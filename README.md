# VeryGoodPlayer

一个基于 **PyQt5** 的桌面音乐播放器，支持**本地音乐播放**与**网易云在线音乐**（搜索、播放、下载），并内置**可交互看板娘**、**桌面歌词**、**主题换肤**等丰富的个性化功能。程序对可选依赖做了优雅降级处理，即使缺少某些库也能正常启动并保留核心能力。

## 功能特性

| 类别 | 功能 |
| --- | --- |
| 本地播放 | 扫描下载目录中的 `mp3 / flac / wav / m4a / ogg / aac / wma` 音频，读取内嵌标签展示曲名/歌手/专辑/时长 |
| 在线音乐 | 接入网易云音乐，支持按**歌名 / 歌手 / 专辑**三种模式搜索，播放与下载 |
| 排行榜 | 内置网易云排行榜（飙升榜、热歌榜、新歌榜等），一键浏览与播放 |
| 发现音乐 | 首页推荐/发现音乐入口，快速探索内容 |
| 猜你喜欢 | 个性化推荐歌曲列表 |
| 播放控制 | 播放/暂停、上一首/下一首、进度拖动、音量调节、静音 |
| 播放模式 | 顺序播放、单曲循环、列表循环、随机播放 |
| 歌词 | 在线歌词自动加载并随播放滚动高亮；本地歌曲读取内嵌歌词 |
| 桌面歌词 | 支持将歌词以悬浮窗口形式显示在桌面上 |
| 收藏 | 一键收藏「我喜欢的音乐」，支持多种排序方式 |
| 我的歌单 | 浏览并播放你创建的歌单 |
| 下载 | 在线歌曲下载到本地（优先无损 flac，回退 mp3/wav/ogg），并自动内嵌封面与歌词 |
| 看板娘 | 可放置在桌面角落的二次元角色，支持切换形象包、置顶、浮动、对话互动 |
| 主题换肤 | 全局主题色实时切换，所有控件/图标/画布随之刷新 |
| 开屏画面 | 启动时的 Splash 启动画面（可在设置中关闭） |
| 状态记忆 | 记住上次音量、上次播放列表、上次播放歌曲、最后浏览的侧栏，重启自动恢复 |
| 缓存管理 | 歌单/封面使用 `diskcache` 磁盘缓存，可在设置中限制歌曲数与总大小 |
| 优雅降级 | `pygame / requests / mutagen / 网易云依赖` 任一缺失时自动降级，不会崩溃 |

## 环境要求

- **Python** 3.8 及以上（推荐 3.9+）
- **Windows** 为主（已针对 Windows 任务栏图标、打包做适配；其它平台理论上可用但未重点测试）
- 见 `requirements.txt` 的依赖

## 安装与运行

1. 克隆或下载本项目到本地：

   ```bash
   git clone <repo-url>
   cd music_player
   ```

2. 安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

   > 各依赖均为可选/按需：
   > - `PyQt5`：必需，UI 框架
   > - `pygame`：本地播放所需，缺失则播放功能不可用
   > - `requests`：在线搜索/下载所需
   > - `mutagen`：读取音频时长与内嵌封面/歌词
   > - `NeteaseCloudMusicApi` / `py_mini_racer` / `pycryptodome`：网易云在线功能
   > - `diskcache`：歌单/封面缓存

3. 启动程序：

   ```bash
   python main.py
   ```

## 打包为可执行文件

项目提供了 PyInstaller 打包配置 `VeryGoodPlayer.spec`：

```bash
pip install pyinstaller
pyinstaller VeryGoodPlayer.spec
```

打包完成后会在 `dist/VeryGoodPlayer/` 生成可执行文件。注意：

- 看板娘资源包（`mascot/` 目录）不打包进 `_internal`，需放在 **exe 同级目录**，用户可自行添加或替换。
- 构建脚本会把 `py_mini_racer` 的 `mini_racer.dll` 放到解压根目录，以保证联网功能在打包后可用。

## 使用说明

### 侧边栏导航

点击左侧菜单在不同页面间切换：

- 🎧 **发现音乐**：在线发现/推荐内容，顶部带搜索栏
- 📊 **排行榜**：网易云各类排行榜，卡片浏览后进入歌曲列表
- 📁 **本地下载**：扫描本地下载目录中的音频文件
- 🎯 **猜你喜欢**：个性化推荐
- 📋 **我的歌单**：你创建的歌单集合
- ❤️ **我喜欢的音乐**：收藏列表
- ⚙ **设置**：偏好设置面板

切换侧栏会自动保存并恢复当前页面的滚动位置。

### 搜索与发现

1. 进入「发现音乐」，顶部工具栏出现 **搜索模式按钮 + 搜索框**。
2. 点击搜索模式按钮可在 **歌名 / 歌手 / 专辑** 间切换（切换后若搜索框已有内容会自动重新搜索）。
3. 输入关键词回车或点击搜索按钮，结果以列表展示，双击即可播放。

### 播放控制

- **播放/暂停**：底部中央按钮，或双击歌曲行。
- **上一首 / 下一首**：底部两侧按钮。
- **进度条**：拖动可定位播放位置（拖动时暂停进度更新，释放后跳转）。
- **音量**：底部音量滑块；点击音量图标可静音/取消静音。

### 播放模式

点击底部模式按钮在以下四种模式间循环切换：

- 顺序播放
- 单曲循环
- 列表循环
- 随机播放

### 歌词

- 在线歌曲：播放时自动从网易云获取歌词并加载，随播放进度滚动并高亮当前句。
- 本地歌曲：自动读取音频文件内嵌歌词（mp3 的 `USLT` 帧 / flac 的 `lyrics` 标签）。
- 支持将歌词以**桌面悬浮窗口**（桌面歌词）形式显示。

### 收藏与歌单

- 在任意歌曲行点击收藏按钮 ❤️，即可加入「我喜欢的音乐」。
- 「我的歌单」可浏览并播放已创建的歌单。
- 收藏列表支持按 **收藏时间（升/降）、曲名（升/降）、歌手（升/降）** 排序，设置可持久化。

### 下载到本地

- 在在线歌曲行点击下载按钮，歌曲将下载到本地下载目录（默认 `songs/`）。
- 下载时优先尝试无损 `flac`，回退到 `mp3`、`wav`、`ogg` 等格式。
- 下载完成后会自动将**歌名、歌手、专辑、封面、歌词**内嵌写入音频文件本体，离线播放无需零散文件。
- 已下载的歌曲会在「本地下载」页面出现，可直接离线播放。

### 设置面板

在「⚙ 设置」页面可配置：

- **主题色**：自定义全局主题色（`#RRGGBB`）。
- **看板娘**：开关、形象包选择、位置、是否置顶、是否浮动、是否显示控制按钮。
- **开屏画面**：启动时是否显示 Splash。
- **下载目录**：自定义本地下载/扫描目录。
- **收藏/本地/歌单排序**：多种排序策略。
- **缓存上限**：最大缓存歌曲数（5–200）、最大缓存体积（50–5000 MB）。
- **音量**：持久化记录。

所有设置实时写入 `config/settings.json`。

### 看板娘

- 位于桌面角落的可交互二次元角色，支持事件触发对话（如播放开始、切歌等）。
- 内置 `Celia`、`test`、`でらっくま` 等形象包，可在设置中切换。
- 支持**拖动摆放位置**、**置顶窗口**、**浮动动画**，也可隐藏。
- 形象包为 `mascot/<包名>/settings.json + 立绘` 结构，用户可自行添加资源包。

### 主题换肤

程序内置全局主题色系统，所有按钮、进度条、图标、表格选中态、画布均读取主题色。切换主题色时实时刷新全部已登记控件，无需重启。

## 快捷键

- 在搜索框中按 **Enter / Return** 触发搜索。
- 播放控制主要依赖界面按钮；部分交互通过鼠标与看板娘按钮完成。

> 提示：更多操作可直接在界面中用鼠标完成，如双击歌曲播放、拖动进度条、点击收藏等。

## 目录结构与数据

```
music_player/
├── main.py                # 程序入口：创建 QApplication、开屏画面、启动主窗口
├── core/
│   ├── player.py          # 主窗口 MusicPlayer，所有核心逻辑
│   ├── netease_api.py     # 网易云音乐接口封装
│   ├── utils.py           # 主题色、路径、可选依赖探测、LRC 解析、内嵌封面/歌词读取
│   └── __init__.py
├── ui/
│   ├── widgets.py         # 通用控件（开屏画面、SVG 渲染等）
│   ├── mascot.py          # 看板娘控件
│   ├── detail_panel.py    # 详情/歌词面板
│   └── __init__.py
├── resources/             # 图标、图片、默认封面等资源（打包时一并分发）
├── mascot/                # 看板娘形象包（运行时从 exe 同级读取，可自定义）
├── config/                # 用户配置（settings.json / favorites.json / playlists.json）
├── songs/                 # 本地下载目录（扫描与存储）
├── requirements.txt
└── VeryGoodPlayer.spec    # PyInstaller 打包配置
```

运行时产生的用户数据：

- `config/settings.json`：全局偏好
- `config/favorites.json`：收藏列表
- `config/playlists.json`：我的歌单
- `songs/`：下载的音频文件
- 缓存目录：由 `diskcache` 管理歌单/封面

## 配置项说明

`settings.json` 主要字段（均由设置面板管理，无需手动编辑）：

| 字段 | 说明 |
| --- | --- |
| `theme_color` | 全局主题色 `#RRGGBB` |
| `volume` | 音量 0–100 |
| `mascot_enabled` | 是否显示看板娘 |
| `mascot_pack` | 当前看板娘形象包 ID |
| `mascot_pos` | 看板娘位置 `{x, y}` |
| `mascot_float` / `mascot_topmost` / `mascot_controls` | 浮动/置顶/控制按钮开关 |
| `splash_enabled` | 启动时是否显示开屏 |
| `download_dir` | 下载目录 |
| `favorites_sort` / `local_sort` / `playlist_sort` / `card_sort` | 各类列表排序方式 |
| `cache_max_songs` / `cache_max_mb` | 缓存上限 |
| `last_menu` / `last_playlist` / `last_playing` / `last_browse_menu` | 重启恢复状态 |

## 可选依赖降级说明

程序在导入关键库失败时仅打印提示并禁用对应功能，不会崩溃：

- 无 `pygame` → 本地播放不可用
- 无 `requests` → 在线搜索/下载不可用
- 无 `mutagen` → 无法读取音频时长与内嵌封面/歌词（显示为占位信息）
- 无网易云依赖 → 在线功能整体不可用，但本地播放与设置照常工作
